# Правки сайта по аудиту 17.11.2026 (SEO 95/100, GEO 60/100)

Источник: seo-audit 2.2.0, запуск на компьютере владельца, 40 из 50 страниц sitemap. P1 (блокеров индексации): 0. Правки кода сайта не выполнены, это список для того, кто правит сайт.

## Сделать в первую очередь (P2 и дешёвые P3)
1. **rel=canonical** на `/request`, `/contact`, `/policy`: `<link rel="canonical" href="https://zookonsierz-maksimvasilevich.msk1.amvera.tech/<путь>">`. Без него Google сам выбирает основной адрес.
2. **robots.txt: позиция по AI-краулерам.** Сейчас её нет (это 0 из 20 баллов GEO и общий потолок GEO 60). Решение за владельцем. Минимум: явно разрешить поисковых (OAI-SearchBot, Claude-SearchBot, PerplexityBot) и отдельной строкой решить про обучающих (GPTBot, ClaudeBot, Google-Extended, CCBot).
3. **sitemap.xml:** убрать `<priority>` и `<changefreq>` (Google их игнорирует); в `<lastmod>` ставить дату реального изменения страницы, а не дату деплоя (сейчас у всех 50 адресов 2026-11-17).
4. **Заголовок главной** 81 символ, сократить примерно до 60: «Зооконсьерж — выгул, зооняня, передержка, зоотакси в Москве».
5. **Заголовки главной:** после h1 идёт h3 («Выгул»), заменить на h2.

## Метаданные
6. **Open Graph** (`og:title`, `og:description`, `og:image`) неполные примерно на 38 страницах. Добавить в общий шаблон; одну картинку 1200×630 для всех.
7. **Meta description** длиннее 160 знаков (сейчас 237) на трёх статьях: `/stati/s-kem-ostavit-pitomca-na-novogodnie-prazdniki`, `/stati/skolko-gulyat-s-sobakoi`, `/stati/kak-vybrat-peredergku`. Сократить до 150–160.
8. **`/policy`** без meta description.
9. **JSON-LD** нет на `/request`, `/contact`, `/policy`, `/stati`, `/goroda`. На главной есть LocalBusiness с двумя sameAs; добавить узел WebSite.
10. **`/contact`** содержит около 100 слов. Добавить правила: часы 06:00–22:00, заказ минимум за 2 часа, заявки 09:00–20:00, «Экспресс», телефон администратора только 09:00–22:00, ночью форма.

## Проверить вручную
11. Единые правила (06:00–22:00; заказ за 2 часа; заявки 09:00–20:00; «Экспресс») есть на сайте во всех местах. Запрещённые фразы: «за сутки», «за 40 минут», «заявки принимаем с 6:00 до 22:00», «обычно за 1–2 часа».
