# Зооконсьерж — Telegram-бот

aiogram 3 + SQLite (aiosqlite) + APScheduler. Запуск: `python bot.py`.
Переменные (см. `.env.example`): BOT_TOKEN, ADMIN_IDS, DB_PATH, POLICY_URL, TIMEZONE.
Админ-команды: `/admin` в боте. Проверка без Telegram: `python tests/e2e_test.py`.
На Railway база должна лежать на томе: `DB_PATH=/data/zoobot.db`.

## Проверка адреса и питомца (v1.1)

- Адрес ищется на карте OpenStreetMap (Nominatim, бесплатно, без ключей): бот показывает до 5 найденных адресов кнопками, можно отправить геопозицию. Район и «за МКАД» определяются по карте. Если карта недоступна, адрес принимается как написан, а в заявке для администратора стоит «⚠️ адрес не подтверждён».
- Кличка, имя, порода и вид животного проверяются (`breeds.py`): мат и набор букв отклоняются, опечатки в породе исправляются подсказкой, редкую породу можно оставить «как написано» (админ увидит пометку в заметках питомца).
- Размер можно написать словом («большой») или весом («12 кг»).
- Тесты: `python3 -m unittest discover -s tests -p "test_*.py"` и `python3 tests/e2e_test.py`.

## Дата и время кнопками

Когда бот спрашивает «Когда?», под вопросом появляется календарь (`datepicker.py`): день → час → минуты, недоступное время не показывается. Текстом тоже можно («12.11 18:30»). Все услуги, кроме зоотакси, записываются не раньше чем за сутки (время подобрать исполнителя); такси — за 30 минут. Правило в `handlers/client.py: min_ahead()`.

## Карта для выбора адреса (мини-приложение)

Кнопка «🗺 Найти на карте» открывает страницу `webapp/index.html` (Leaflet + OpenStreetMap, подсказки Photon): адрес подсказывается по мере набора, а дом можно выбрать касанием по карте. Результат приходит боту как `web_app_data`, координаты и текст перепроверяются (`geo.parse_pick`).
Страницу отдаёт веб-сервер внутри бота (`webserver.py`, порт из `PORT`). Кнопка появляется, когда известен публичный адрес: переменная `WEBAPP_URL` или `RAILWAY_PUBLIC_DOMAIN` (Railway ставит её сам, когда у сервиса есть домен). Без домена бот работает как раньше: адрес текстом или геопозицией.

## Тесты

- `python3 -m unittest discover -s tests -p "test_*.py"` — юнит-тесты;
- `python3 tests/e2e_test.py`, `python3 tests/e2e_pricing.py`, `python3 tests/e2e_wpage.py` (нужен Playwright) — сквозные;
- `python3 tests/fuzz_test.py <seed> <шагов>` — фаззинг (случайные сообщения, кнопки, админ-команды; проверка целостности БД).
